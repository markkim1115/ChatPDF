# ChatPDF

복사할 때 줄바꿈과 누락된 단어 간격을 보정하는 macOS PDF 리더입니다. 형광펜, 영역 OCR, PDF 안에서의 ChatGPT 대화를 지원합니다.

## 설치

**필요 환경:** macOS 14 이상, Swift 6 이상의 Command Line Tools. 현재는 소스에서 설치합니다.

1. **터미널**을 엽니다. 개발 도구가 없다면 `xcode-select --install`을 실행하고 설치를 마칩니다.
2. 아래 명령을 차례로 실행합니다. 기존 ChatPDF가 실행 중이면 먼저 종료합니다.

```sh
git clone https://github.com/markkim1115/ChatPDF.git
cd ChatPDF
sh scripts/run.sh
```

빌드가 끝나면 **응용 프로그램 → ChatPDF**에 설치되고 자동으로 열립니다. 처음 빌드할 때는 몇 분 걸릴 수 있습니다. 저장소가 비공개인 동안은 GitHub 접근 권한이 필요합니다.

## 사용

PDF를 창으로 끌어 놓거나 `⌘O`로 엽니다.

| 할 일 | 방법 |
| --- | --- |
| 줄바꿈 없이 복사 | 텍스트 선택 → `⌘C` → 원하는 앱에 붙여넣기 |
| 원문 그대로 복사 | `⇧⌘C` |
| 형광펜 표시 | 텍스트 선택 → `⇧⌘H` |
| 형광펜 삭제 | 표시를 클릭 → `Delete` |
| 스캔·이미지에서 텍스트 복사 | `⇧⌘O` → 영역 드래그 → 결과 확인 → **복사** |
| 저장 / 실행 취소 | `⌘S` / `⌘Z` |
| 문서 검색 | `⌘F` |
| PDF에 질문 | 툴바 **ChatGPT** → 질문 입력 → `Enter` |

복잡한 수식·표·다단 문서는 복사 결과를 확인해 주세요. 형광펜은 저장하면 미리보기 등 다른 PDF 앱에서도 볼 수 있습니다.

## ChatGPT와 개인정보

ChatGPT 기능은 선택 사항이며, 호환되는 ChatGPT/Codex 데스크톱 앱과 **본인 계정**이 필요합니다. 같은 Mac 사용자에 저장된 로그인을 사용하고, 필요하면 대화창의 **로그인**으로 연결합니다. 배포자의 계정이나 인증 정보는 포함하지 않습니다.

읽기·복사·형광펜·OCR은 기기에서 처리합니다. **질문을 보내면 질문과 선택한 텍스트, 답변에 필요한 PDF 내용이 OpenAI로 전송됩니다.** 대화 기록과 별도로 보낸 PDF 사본은 Mac에 남습니다. [보안 점검 및 저장 위치](SECURITY.md)를 참고하세요.
