# PDF Reader

macOS용 네이티브 PDF 리더. Apple PDFKit의 벡터 렌더링과 AppKit의 문서 창을 사용하며, 기본 복사에 줄바꿈 보정을 적용합니다. 읽기·편집·OCR은 기기 안에서 처리하며, 선택 기능인 ChatGPT 대화는 OpenAI에 연결합니다.

## 실행

macOS 14 이상과 Swift 6 이상이 필요합니다. 현재 Mac의 Command Line Tools로 빌드할 수 있습니다.

```sh
git clone https://github.com/markkim1115/ChatPDF.git
cd ChatPDF
sh scripts/run.sh
```

`run.sh`는 `/Applications/PDF Reader.app`을 업데이트하고 실행합니다. 실행 중인 앱이 있으면 먼저 종료해 주세요. 빌드만 하려면 `sh scripts/build.sh`를 사용합니다. 중간 결과물은 숨김·인덱싱 제외 폴더인 `build/.staging.noindex/PDF Reader.app`에 두어 ‘다음으로 열기’의 중복 등록을 피합니다. 배포 인증서 없이 로컬 ad-hoc 서명으로 빌드됩니다. 이전 버전 백업은 `.app` 사본 대신 `.zip`으로 보관합니다.

## 사용

PDF를 창에 놓거나 `⌘O`로 엽니다. 시작 화면에는 기능을 직접 확인할 수 있는 2페이지 예제 문서가 있습니다.

| 동작 | 단축키 |
| --- | --- |
| 기본 복사 — 줄바꿈 보정 기본 켜짐 | `⌘C` |
| 원문 줄바꿈 그대로 복사 | `⇧⌘C` |
| 설정과 관계없이 줄바꿈 보정하여 복사 | `⌥⌘C` |
| 이미지·스캔 영역 텍스트 인식 | `⇧⌘O` |
| 선택 영역 형광펜 | `⇧⌘H` |
| 클릭한 형광펜 또는 선택 영역의 형광펜 삭제 | `Delete` |
| 저장 / 다른 이름으로 저장 | `⌘S` / `⇧⌘S` |
| 형광펜 실행 취소 / 다시 실행 | `⌘Z` / `⇧⌘Z` |
| 검색 / 다음 결과 / 이전 결과 | `⌘F` / `⌘G` / `⇧⌘G` |
| 페이지 맞춤 / 실제 크기 | `⌘0` / `⌘1` |
| 이전 / 다음 페이지 | `⌘↑` / `⌘↓` |
| PDF 안의 ChatGPT 대화창 열기 / 닫기 | `⌥⌘G` |

툴바의 **줄바꿈 보정** 설정은 다음 실행에도 유지됩니다. 형광펜 옆 메뉴에서 노랑·초록·파랑·분홍을 선택하거나 선택 영역의 형광펜을 지울 수 있습니다. 표시된 형광펜을 클릭한 뒤 `Delete`를 누르거나 우클릭 메뉴의 **형광펜 지우기**를 사용할 수 있습니다. 주석은 표준 PDF 형식으로 저장하므로 macOS 미리보기에서도 표시됩니다. 저장하지 않은 변경이 있으면 창을 닫을 때 확인합니다.

## PDF 안에서 ChatGPT와 대화

툴바의 **ChatGPT** 버튼 또는 `⌥⌘G`를 누르면 오른쪽 대화창이 열립니다. 질문하고 Enter를 누르면 답변이 이 창에 표시됩니다. Shift+Enter는 줄바꿈, **중지**는 답변 중단입니다. 모델 메뉴에는 현재 계정에서 사용 가능한 이미지 지원 모델이 표시됩니다.

PDF와 대화창 사이의 손잡이나 넓은 세로 구분선을 드래그하면 대화창 너비를 조절할 수 있습니다. 같은 문서 창에서 대화창을 닫았다 다시 열면 조절한 너비를 유지합니다.

세션 이름은 확장자를 포함한 PDF 파일명으로 지정합니다. 기존 대화도 다시 연결하면 파일명으로 갱신하며, 다른 이름으로 저장한 뒤 질문하면 새 파일명을 반영합니다.

이 Mac에 설치된 ChatGPT 데스크톱 앱의 공식 [Codex app-server](https://developers.openai.com/codex/app-server)를 사용합니다. 기존 ChatGPT 로그인을 사용하며 API 키를 입력하지 않습니다. 로그인이 필요하면 대화창의 **로그인**을 누르고 브라우저에서 완료합니다. ChatGPT/Codex 계정의 이용 한도와 모델 접근 권한이 적용됩니다.

현재 페이지 번호와 선택한 문장이 질문에 함께 전달됩니다. 답변에 필요한 페이지의 텍스트, 주석, 이미지가 OpenAI로 전송되며, 읽지 않은 페이지를 미리 모두 업로드하지 않습니다. 스캔·그림·수식은 페이지 이미지로 확인할 수 있습니다. 답변의 페이지 링크를 누르면 해당 PDF 페이지로 이동합니다. 잠긴 PDF나 복사를 금지한 PDF에서는 사용할 수 없습니다.

각 질문은 저장하지 않은 주석까지 포함한 PDF 사본을 메모리에 준비합니다. 같은 파일 경로를 다시 열면 기존 대화를 이어가며, 대화 내용과 연결 ID는 `~/Library/Application Support/PDF Reader/Assistant/Conversations/`에 저장합니다. 실제 모델 대화 기록은 app-server의 로컬 저장소에도 보관됩니다. **새 대화** 버튼은 현재 대화를 별도 JSON 파일로 보관하고 새 대화를 시작합니다. 앱을 닫을 때 미완료 답변은 다음 실행에서 안내합니다.

대화창에서 제공하는 문서 도구는 페이지 읽기·검색·이미지 확인 세 가지이며, 일반 셸·브라우저·다른 앱 도구는 활성화하지 않습니다. ChatGPT 데스크톱 앱에 포함된 app-server의 실험적 문서 도구 인터페이스를 사용하므로, 향후 ChatGPT 업데이트에 맞춘 조정이 필요할 수 있습니다.

### 별도 ChatGPT 앱으로 보내기

파일 메뉴의 **ChatGPT 앱으로 보내기**를 누르면 ChatGPT 데스크톱 앱의 새 로컬 채팅이 열립니다. 문서 전체를 읽어 요약하는 질문과 현재 페이지 번호가 입력되어 있으며, ChatGPT에서 **전송**을 누르면 시작합니다.

버튼을 누른 시점의 PDF 사본을 `~/Library/Application Support/PDF Reader/ChatGPT/`에 보관합니다. 저장하지 않은 형광펜 표시도 포함하며 원본 PDF는 변경하지 않습니다. 이전 채팅에서도 읽을 수 있도록 사본을 유지하므로, 이 폴더의 파일을 삭제하면 해당 채팅의 파일 접근이 끊깁니다. ChatGPT의 공식 `codex://new` 링크로 로컬 작업 폴더와 질문을 전달하며, 파일을 읽을 수 있는 로컬 Work/Codex 기능과 해당 폴더 접근 권한이 필요합니다. 잠긴 PDF와 복사를 허용하지 않는 PDF에서는 버튼이 비활성화됩니다.

## 복사 보정 방식

- 기본 `⌘C`, 편집 메뉴, 문서의 복사 메뉴를 보정 경로에 연결합니다.
- 클립보드에는 보정된 일반 텍스트만 넣어, 붙여넣는 앱이 줄바꿈이 남은 RTF를 우선 사용하지 않게 합니다.
- 저장된 글자 순서가 뒤집힌 PDF는 지면의 열과 줄 좌표로 읽기 순서를 복원합니다. 분수·악센트처럼 겹친 조각은 같은 영역에 묶고, 회전된 글자는 원래 순서를 유지합니다.
- 단일 지면 줄바꿈을 공백으로 바꿉니다. 줄의 대표 글꼴 크기와 원본 글자 기준선·줄 간격·들여쓰기를 이용해 문단을 구분합니다. 첫 글자를 크게 꾸민 문단도 이어 붙이며, 문장 안의 `(1)`, `(2)`, `(3)`은 줄 시작에 있다는 이유만으로 목록으로 바꾸지 않습니다.
- PDFKit이 양끝 정렬 문장에서 공백을 누락한 경우, PDF의 실제 글꼴 너비와 글자 배치 명령으로 단어 사이 간격을 복원합니다. 단어를 사전으로 추측해 분리하지 않으며, 작은 자간 조정은 유지합니다. 해석할 수 없는 글꼴 인코딩과 세로·회전 조판은 원래 추출 결과를 유지합니다.
- 같은 단 안에서 드래그할 때는 줄과 글자의 위치를 기준으로 선택을 실시간 갱신해 옆 단이 함께 선택되거나 첫 줄·마지막 줄이 누락되지 않도록 합니다. 여러 페이지·여러 단을 가로지르는 드래그와 회전된 페이지는 PDFKit의 선택을 유지합니다.
- 선택 영역의 바깥 텍스트를 복사하지 않습니다. 줄의 전체 좌표는 배치 판별에, 같은 페이지의 표기는 하이픈 판단에만 사용합니다.
- soft hyphen은 제거합니다. 줄 끝에서 분리된 영어 단어는 완성된 단어의 사전 확인 또는 같은 페이지의 표기로 연결합니다. 같은 페이지에서 줄 중간에 쓰인 합성어 표기를 존중하며 `ResNet-like` 같은 모델명도 보존합니다. `night-time`/`nighttime`처럼 양쪽이 모두 가능한 경우 연결된 표기로 정규화될 수 있습니다.
- 두 단에 걸친 본문을 선택할 때, 왼쪽 단 하단의 작은 각주를 지나 오른쪽 단에서 같은 문장이 이어지는 경우 끼어든 각주를 제외합니다. 각주만 선택하면 그대로 복사합니다.
- 악센트와 바탕 글자가 겹쳐 그려진 이름은 좌표를 확인해 `ń` 같은 하나의 문자로 복원합니다.
- 복사 보정은 클립보드에만 적용됩니다. PDF 본문의 내용과 배치를 바꾸지 않습니다.

## 검증

```sh
swift test --disable-xctest
sh scripts/build.sh
```

현재 Mac의 Swift 6.4 Command Line Tools에서 `TestingMacros` 자동 탐색 오류가 발생하면, 설치된 매크로 경로를 명시하여 테스트합니다.

```sh
swift test --disable-xctest -Xswiftc -load-plugin-library -Xswiftc /Library/Developer/CommandLineTools/usr/lib/swift/host/plugins/testing/libTestingMacros.dylib
```

Swift Testing으로 실제 CoreText PDF와 공백 문자 없이 글자를 배치한 PDF를 생성하여 사용자 예문, 누락된 공백, 자간·글꼴·좌표 변화, 장식 대문자, 악센트, 문단, 제목, 목록, 부분 선택, 각주 선택, 페이지 간 연결, 클립보드의 원문/보정 동작, 형광펜의 저장·재열기를 검증합니다. 테스트는 전용 클립보드를 사용합니다.

PDF 대화 테스트는 실제 PDF의 페이지 읽기·검색·이미지 생성, 저장하지 않은 주석, 대화 저장, 분할된 UTF-8 응답 처리를 검증합니다. `PDFREADER_LIVE_CHAT_TEST=1`을 테스트 명령 앞에 붙이면 로그인된 ChatGPT 계정으로 합성 PDF를 읽고 이미지를 확인한 뒤 대화를 재개하는 통합 테스트도 실행합니다. 이 선택적 테스트는 계정 이용량을 사용하며, 사용자 PDF는 전송하지 않습니다.

아래 논문 검증 기록은 개발 환경에서 수행한 과거 검사입니다. 논문 원본, 개인 파일 경로가 포함된 `qa/`, 임시 작업 폴더 `tmp/`, 빌드 결과물은 GitHub 저장소에 포함하지 않습니다. 위의 자동 테스트와 앱 빌드에는 이 자료가 필요하지 않습니다.

로컬 논문 61편의 본문 문단에 대한 재현 자료와 기대 결과는 개발 환경의 `qa/2026-10-08-copy-fix/`에 보존했습니다. 이전 50편 및 10편의 검사 결과도 로컬에 보존했습니다. 논문 전체 페이지의 정확도를 보증하는 검사는 아닙니다.

기존 40편(760쪽)의 7,361개 본문 후보에 대한 양방향 선택·형광펜 삭제 검사 기록은 로컬 `qa/2026-10-12-interaction-40/report.html`에 있습니다. 40편의 대표 문단 69개에서는 앱의 마우스 이벤트 처리, 복사, Delete, Undo/Redo, 저장·재열기를 함께 검사했습니다. 수식·그림·표가 본문 후보로 합쳐진 영역의 남은 선택 제약은 보고서에 구분했습니다.

`Sources/PDFReaderCore`에는 텍스트 보정, PDF 선택 추출, 복사 처리, 주석 처리가 있습니다. `Sources/PDFReader`에는 문서 저장과 실행 취소, 창, 메뉴, 비동기 검색, 시작 화면이 있습니다.

## 현재 범위

텍스트 레이어가 있는 PDF는 기존의 드래그 → `⌘C`를 사용합니다. 이미지·스캔 문서나 텍스트 레이어가 잘못된 영역은 툴바의 **영역 텍스트 인식** 또는 `⇧⌘O`를 누르고 한 페이지 안의 문단을 드래그합니다. 맥의 Vision으로 기기 안에서 인식하며, 결과 창에서 확인·수정한 뒤 **복사**합니다. 영역 선택은 Esc로 취소할 수 있습니다. OCR은 영문·한글을 지원하지만 수식·작은 글자·URL에는 오인식이 남을 수 있습니다. 문단 판별은 PDF의 텍스트 순서와 좌표에 의존하므로 복잡한 표·수식·다단 조판 전체 선택에서는 원문 복사와 비교가 필요할 수 있습니다. 문서가 지정한 복사·주석 권한을 따릅니다.

PDFKit에 렌더링·썸네일·스크롤을 맡기고 검색은 비동기로 수행합니다. 모든 페이지를 이미지로 미리 변환하지 않으며, 원본 글꼴·벡터·이미지를 그대로 표시합니다. 미리보기와의 대용량 문서 성능 동등성을 벤치마크로 보증한 것은 아닙니다.

API 참고: [Apple PDFKit](https://developer.apple.com/documentation/pdfkit), [PDFSelection](https://developer.apple.com/documentation/pdfkit/pdfselection).

40편 760쪽의 전체 텍스트 블록 재검사, 수정 전후 비교 및 OCR 검증 결과는 `qa/2026-10-08-repair/report.html`에 있습니다. 확인된 표 영역 94개를 제외하고 16,455개 블록을 검사했습니다. 일부 선 없는 표는 보조 결과에 남으며, 추출기 간 차이를 전부 오류나 정답으로 간주하지 않습니다.
